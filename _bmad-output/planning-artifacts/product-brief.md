# 实验室设备预约管理系统产品简报

## 问题陈述

高校教学实验室通过微信群、电话联系管理员，再用纸质表格或 Excel 登记预约。设备空闲情况不透明，预约需要反复询问，人工登记容易遗漏或发生时间冲突，变更通知不及时。

本系统采用 Web 网页形式，支持电脑和手机浏览器，面向投影仪、笔记本电脑、摄像头、开发板等普通共享设备，提供登录、设备查询、预约申请、冲突检查、管理员审核、预约取消、状态查询和设备维护，优先保证核心流程完整、冲突处理正确、容易部署和测试。

预约按具体设备唯一编号管理，不做同型号设备自动分配。提交成功即占用，待审核及已批准的预约均阻止重叠申请，拒绝或取消后释放；长期未审核申请由管理员人工处理。允许预约未来日期，以整点为单位、至少 1 小时、单次不跨自然日，相邻时段可预约，不设置额外缓冲时间。同一设备不能存在相互冲突的有效预约。

用户只能取消自己尚未开始的待审核或已批准预约；管理员取消须记录原因并保留操作记录。设备维修或停用后立即禁止新申请，保留历史记录，既有受影响预约由管理员人工处理。用户在系统内查看审核结果、预约状态和取消原因。

## 目标用户

计划服务约 **58 人**：学生约 **50 人**、教师约 **6 人**、实验室管理员约 **2 人**。学生和教师查询设备、提交和管理自己的预约；管理员维护设备信息、审核预约并处理设备停用情况。

## 预期成功度量

| 目标 | 衡量标准 |
| --- | --- |
| 预约信息透明 | 上线一个月后，有权限的用户可以查询 100% 的预约记录及其对应状态。 |
| 管理效率 | 处理同样 20 条预约记录，管理员核对耗时相比现有方式降低至少 50%。 |
| 并发一致性 | 20 个请求同时竞争同一设备相同时段，最终最多产生 1 条有效占用预约。 |
| 使用便利 | 至少 3 名潜在用户参与试用，其中至少 2 人可在 3 分钟内独立完成设备查询和预约申请。 |

## 明确不做的范围

在线支付、采购报销、智能推荐、自动候补、自动签到处罚、危险设备资格认证、离线补录、跨天及周期预约、复杂数据分析、临时锁定和自动过期释放、独立手机 App 及微信小程序、外部短信邮件微信通知。
