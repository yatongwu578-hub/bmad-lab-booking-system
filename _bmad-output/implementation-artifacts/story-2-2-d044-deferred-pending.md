## Deferred from: Story 2.2 full code review and D-044 (2026-11-26)

- **2.2-P1（Medium，故障绑定取证）**。第二次审计 INSERT 的原始 `bind` 记录采于注入前，不是送给 PostgreSQL 的实际执行值。真实 23514、两次 INSERT 尝试、零 COMMIT 和独立业务快照等值仍支持 AC-8 原子回滚。残余风险是以后把原值误读为执行值，无法仅凭旧 JSONL 还原故障参数。下次维护故障探针时分录注入前与实际执行绑定，并用真实故障和独立读回验证。
- **2.2-P2（Low，清理标记）**。旧探针先报 `cleanup=true` 再比较前后基线，本批有独立清理快照及完整退出链。残余风险是单读失败批次的标记会误判。下次维护探针失败记录时，将成功标记放在比较通过后，保留失败退出及原始证据。
- **2.2-P3（Low，散列清单）**。原包装前后使用同一份路径枚举，后来新增的文件可能不入清单。现有独立入口在新运行结束另核当前实际文件集合及逐项散列。残余风险是绕开外层入口会弱化新增文件检测。下次维护原包装时在每次快照重新枚举。
- **2.2-P4（Low，三角色日期控件）**。当前服务端详情入口、表单与实际查询路径一致，真实 HTTP 三角色对照通过，但自测没有在 Chrome 上操作所渲染的日期控件。残余风险是后续 action、method 或字段名漂移未被现有自动化检出。经另行授权的正式运行实际选日和返回导航补证，下次维护浏览器或导航回归时补自动化。
- **2.2-P5（Low，混合日期）**。当前实现把已结束历史和有效占用一起排序计算补集，原测试已覆盖各自边界。残余风险是两类同日组合的补集退回错误排序不一定被发现。下次维护占用区间规则回归时加混合日精确补集。
- **2.2-P6（Low，区间 HTML）**。现有模板有历史及未占用区间循环，现有测试较多核对上下文，未逐行锁定这两组渲染。残余风险是模板未来漏掉某条时段而上下文测试仍过。下次维护占用模板回归时核对实际 HTML 区间行。
- **2.2-D1（Low，沿用 RD01）**。Story 2.2 包装会打开现有旧入口锁，不能覆盖旧入口在锁文件不存在时随后启动的竞态。并跑会污染隔离取证，不影响正式产品。当前同库串行，统一隔离验证入口时复核共享租约。原 RD01 不闭合。
