# Story 2.7 · 主线实施规格

以[正式 AC-1～8](../planning-artifacts/epics.md#story-27-管理员拒绝待审核预约)为准。本页是直接实现候选在独立复核和人工验收后的主线记录，不表示 Y 首稿曾使用 BMAD Build、正式 AC 或架构上下文。

| AC | 行为与证据 |
| --- | --- |
| 1 | 授权管理员在开始前凭非空原因拒绝原待审核预约；隔离正例及组合拒绝释放占用，可重新申请原区间。 |
| 2 | 非待审核不重复拒绝；锁后重新采样再拒绝。组合批准先行后，拒绝返回 409 且无写入。 |
| 3 | 已到期的范围内目标仅按 FR-018 提交系统失效及一条系统历史。隔离边界、非目标不变及重复拒绝零写。 |
| 4 | 角色、目标与 CSRF 前置拒绝，无泄露或业务副作用；隔离坏载荷及权限，正式匿名/学生同一终态详情负例。 |
| 5 | 空白原因不产生拒绝。隔离未来空白 400 无写，到期空白按锁后判时保留合法失效及系统历史。 |
| 6 | 本人可见授权原因，异主不可见；拒绝与失效历史按目标核对真实角色、前后状态及判时。组合拒绝历史实证。 |
| 7 | 同一设备锁、锁后重读、唯一取时；独立取消、失效、拒绝与组合批准/拒绝竞争。 |
| 8 | 确认数据库回滚与结果未知处理分离，保持状态及历史原子性、不重试；隔离实际 COMMIT 拒绝及确认丢失注入，组合提交前后观测。 |
