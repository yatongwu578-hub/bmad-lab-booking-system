# Story 2.6 · 主线实施规格

以[正式 AC-1～8](../planning-artifacts/epics.md#story-26-管理员批准待审核预约)为准。本页是已验收实现的主线归档，并不替代 X 实验工作区经历过复核的原规格或 S0。按 D-058，继续使用正常申请入口已验证且不可直接编辑的原时段，不扩大历史数据或导入范围。

| AC | 行为与证据 |
| --- | --- |
| 1 | 开始前批准原待审核记录，不更换预约或重复占用。隔离正常申请、批准和组合竞争证实只保留原占用、仅一条批准历史。 |
| 2 | 业务管理员和目标授权先行，等锁后再次校验；隔离角色、CSRF、伪造数据和撤权负例。正式匿名/学生被拒，管理员可读取合格详情。 |
| 3 | 锁后重读及唯一数据库判时；实测顺序、锁等待跨开始时间和相等边界。 |
| 4 | 按最新设备状态处理，不可用不批准；恢复后仍重核，隔离维修、停用、恢复正反例。 |
| 5 | 非待审核及不存在的预约不再批准。组合拒绝先行后，批准返回 409 且无写入。 |
| 6 | 到期仅对范围内目标按 FR-018 失效，保留系统历史，不写批准历史。隔离边界及非目标不变证据。 |
| 7 | 既有设备锁、取时和事务协议统一；真实批准/拒绝双序、申请、查询、失效交错证据。 |
| 8 | 已确认回滚时状态与历史一起回滚；未知结果待核查、不重试。隔离事务边界实证结合组合提交前后观测。 |
