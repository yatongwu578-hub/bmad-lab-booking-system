## 4. 吴亚彤在启动前与实验前的决定

Sprint 1 启动前由团队核定排程、可用工时及分工，估算 2.1 完整验证与后续综合工作，由吴亚彤确认可行性并单独批准启动。技术延期项在既定节点确认和取证，T-02 须在 2.1 ready 前完成真实技术复核，运行证据随验收取得。

实验前必须人工确认：

1. 2.6/2.7可比性及不等价部分；两条均尚未开发，最终X/Y分派和最小Y输入。
2. 同一共同起点的实际版本/哈希、允许代码/文件清单、隔离副本及测试库；不含任一实验实现或专用答案。记录共享既有代码提供架构线索的局限。
3. X完整BMAD输入及独立bmad-build会话；Y独立干净会话，不读PRD/ADR/PC/故事卡、其他会话或X代码；校验自动注入、祖先AGENTS和连接器检索等泄漏路径，不能仅靠提示语隔离。Y路径如何与普通bmad-build纪律衔接，先确认，不静默破坏实验条件。
4. 同人/同日/同宿主/同模型、相同工具能力、统一独立code-review标准及适用清单；两组真实测试和验收标准同等严格。
5. 实际输入/会话/产物/首轮评审/测试输出归档，五项度量定义、分母、去重与返工观察期；结果均待测，允许净收益为负。若隔离无法保证，先暂停该实验并由负责人决定，不能当作有效干净对照。
